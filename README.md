# 🚀 DevHub - LeetCode & GFG Pattern-Wise Interview Navigator
DevHub is a modern, responsive single-page web application designed for software engineers and students preparing for technical coding interviews. It features a sleek glassmorphic authentication gateway that unlocks curated, pattern-wise question roadmaps from both **LeetCode (Top 150)** and **GeeksforGeeks (Must-Do)**.
## ✨ Features
- **🎨 Modern Glassmorphism UI:** Built with animated floating gradient background orbs, frosted glass effects, and responsive CSS Grid/Flexbox layouts.
- **🔐 Interactive Authentication:**
  - Tabbed interface switching between **Sign In** and **Register**.
  - Client-side validation with password matching and show/hide visibility toggles.
  - Dynamic user personalized greeting on successful login.
- **📚 Curated Pattern-Wise Question Banks:**
  - **LeetCode Mode:** Top 150 standard interview questions organized across 23 core algorithmic patterns.
  - **GeeksforGeeks Mode:** High-frequency, company-favorite interview problems organized across 11 key patterns.
- **⚡ Live Search & Filter:** Real-time search by question name, number, or pattern, with instant difficulty filtering (**All / Easy / Medium / Hard**).
- **🔗 Direct Practice Links:** Clickable problem items that navigate directly to the official problem URLs on LeetCode and GeeksforGeeks in a new tab.
  
## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure.
- **CSS3:** Custom styling with CSS Grid, Flexbox, keyframe animations, and backdrop filters.
- **Vanilla JavaScript:** Real-time DOM manipulation, search/filter algorithms, and view state routing.
